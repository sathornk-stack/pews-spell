# PEWS-spell — คู่มือติดตั้งและดูแลระบบ

แอปประเมิน Pediatric Early Warning Sign – Hypoxic Spell
หน่วยกุมารเวชศาสตร์โรคหัวใจ คณะแพทยศาสตร์ มหาวิทยาลัยขอนแก่น

เอกสารนี้สำหรับคนที่ดูแลระบบ ไม่ใช่สำหรับพยาบาลผู้ใช้งาน
รุ่นของชุดนี้ดูได้จากไฟล์ `VERSION`

---

## 1. อ่านตรงนี้ก่อน — ทำไมต้องเอาไปวางบนโฮสต์เอง

ลิงก์ `claude.ai/artifact/...` ที่ใช้ทดลองกันมา **ใช้กับงานจริงไม่ได้**

หน้านั้นไม่ใช่ตัวแอป แต่เป็นหน้าของเว็บ Claude ที่ไปโหลดแอปมาแสดงในกรอบอีกทีหนึ่ง
พอสแกน QR บนมือถือ เครื่องจึงพาไปที่ Claude ก่อน และถ้าเครื่องนั้นลงแอป Claude ไว้
ระบบจะโยนลิงก์เข้าแอป กลายเป็นหน้าแชตแทนที่จะเป็นแอปประเมิน

ชุดไฟล์ในโฟลเดอร์นี้คือเวอร์ชันสำหรับใช้งานจริง วางบนโฮสต์ไหนก็ได้
แล้วจะได้ URL ที่เปิดเข้าแอปตรง ๆ ไม่ผ่านอะไรทั้งสิ้น

---

## 2. ของในโฟลเดอร์นี้คืออะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด — HTML, CSS, JavaScript และภาพ flow ส่วนที่ 3 อยู่ในไฟล์เดียว |
| `sw.js` | service worker ทำให้เปิดใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต |
| `manifest.webmanifest` | ทำให้ติดตั้งลงหน้าจอโฮมได้เหมือนแอป |
| `fonts/` | ฟอนต์ Sarabun และ IBM Plex Mono ที่ฝังมาด้วย |
| `icon-*.png`, `apple-touch-icon.png` | ไอคอนบนหน้าจอโฮม |
| `.nojekyll` | บอก GitHub Pages ไม่ต้องประมวลผลไฟล์ |
| `VERSION` | หมายเลขรุ่นที่ build |

**ทั้งหมดเป็นไฟล์นิ่ง** ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีฐานข้อมูล ไม่ต้องมีบัญชีผู้ใช้
และหลังโหลดครั้งแรกไม่เรียกอะไรจากอินเทอร์เน็ตเลยแม้แต่ตัวเดียว

## 3. เอาขึ้นโฮสต์

### ทางด่วน ใช้เวลา 2 นาที — เหมาะกับการสาธิตหรือทดลองใช้

1. เปิด `app.netlify.com/drop`
2. ลากโฟลเดอร์ `pews-spell` ทั้งโฟลเดอร์ไปวางในหน้านั้น
3. ได้ URL ทันที เป็น HTTPS ใช้งาน offline ได้ครบ

ไม่ต้องสมัครอะไร แต่ถ้าไม่สมัครบัญชี ลิงก์จะอยู่ชั่วคราว
ใช้สาธิตในที่ประชุมได้ ยังไม่เหมาะเอาไปพิมพ์ลงโปสเตอร์

### ทางถาวร ใช้เวลา 10 นาที — GitHub Pages ฟรี

1. สร้างบัญชี GitHub แล้วสร้าง repository ใหม่ ตั้งชื่อ `pews-spell` เลือก **Public**
2. กด **Add file → Upload files** ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ลงไป
   (ลากตัวไฟล์เข้าไป ไม่ใช่ลากโฟลเดอร์ครอบ — `index.html` ต้องอยู่ชั้นบนสุด)
3. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch**
   แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
4. รอ 1–2 นาที จะได้ที่อยู่ `https://<ชื่อบัญชี>.github.io/pews-spell/`

### ทางที่ดีที่สุดในระยะยาว — เซิร์ฟเวอร์ intranet ของโรงพยาบาล

ก๊อปปี้ไฟล์ทั้งหมดไปวางในโฟลเดอร์ที่เว็บเซิร์ฟเวอร์ให้บริการอยู่ แค่นั้น
ปลอดภัยที่สุดในแง่ข้อมูลผู้ป่วยและธรรมาภิบาล แต่ต้องคุยกับ IT และเขาต้องรับดูแลต่อ

> **ทุกทางต้องเป็น HTTPS** ถ้าเปิดผ่าน `http://` ธรรมดาหรือเปิดไฟล์ตรง ๆ แบบ `file://`
> ระบบ offline จะไม่ทำงาน และจะไม่มีอะไรฟ้องให้รู้ตัว

## 4. ทำ URL ถาวรก่อนพิมพ์ QR code

**อย่าพิมพ์ QR ที่ชี้ไปที่อยู่ของ Netlify หรือ GitHub โดยตรง**
วันที่ย้ายโฮสต์คือวันที่โปสเตอร์ทุกแผ่นที่ติดทั่วโรงพยาบาลตายพร้อมกัน

ให้ซื้อโดเมนสั้น ๆ สักอัน (ประมาณ 300–500 บาทต่อปี) ตั้ง redirect ไปยังที่อยู่จริง
แล้วพิมพ์ QR ที่ชี้ไปที่โดเมนนี้ ย้ายแอปไปไหนก็แค่แก้ redirect

## 5. ทดสอบก่อนใช้จริง (ต้องทำ)

ทำบนมือถือจริง ไม่ใช่คอมพิวเตอร์ และทดสอบทั้ง Android และ iPhone อย่างละเครื่อง

- [ ] เปิดที่อยู่นั้นบนมือถือ หน้าเว็บขึ้นครบ ฟอนต์ไทยไม่เพี้ยน
- [ ] กดเมนูแชร์ → **เพิ่มไปยังหน้าจอโฮม** มีไอคอนไดโนเสาร์ขึ้นจริง
- [ ] เปิดจากไอคอนบนหน้าจอโฮม ไม่มีแถบที่อยู่ของเบราว์เซอร์
- [ ] **ปิดไวไฟและปิดเน็ตมือถือ** แล้วเปิดแอปจากไอคอน — ต้องเปิดได้ตามปกติ
- [ ] ขณะยังปิดเน็ต กรอกบัตรข้างเตียงและให้คะแนนหนึ่งรอบ — ต้องคิดคะแนนได้
- [ ] ขณะยังปิดเน็ต เปิดแท็บ **แนวทาง** — ภาพ flow ต้องขึ้นครบทั้งสี่สี
- [ ] เปิดเน็ตกลับ ปิดแอป เปิดใหม่ — ข้อมูลที่กรอกไว้ยังอยู่

ถ้าข้อที่ปิดเน็ตแล้วเปิดไม่ได้ สาเหตุที่พบบ่อยที่สุดคือเปิดผ่าน `http://` แทน `https://`

## 6. เวลาต้องแก้แอป

1. แก้ `index.html` ด้วย text editor อะไรก็ได้
2. **สำคัญ** เปิด `sw.js` แก้บรรทัด `var CACHE = 'pews-spell-...'`
   เปลี่ยนเลขท้ายเป็นอะไรก็ได้ที่ไม่ซ้ำของเดิม
   ถ้าไม่เปลี่ยน เครื่องที่ติดตั้งไว้แล้วจะใช้เวอร์ชันเก่าต่อไปเรื่อย ๆ
3. อัปโหลดทับ

เครื่องผู้ใช้จะเห็นแถบ "มีเวอร์ชันใหม่" ตอนเปิดครั้งถัดไป
ถ้าไม่กด ก็จะอัปเดตเองตอนเปิดรอบถัดไปอยู่ดี

**ภาพ flow ในแท็บแนวทางฝังอยู่ใน `index.html`** ถ้าแนวทางส่วนที่ 3 แก้
ต้องสร้างภาพใหม่แล้วฝังกลับเข้าไป ไม่ใช่แค่เปลี่ยนไฟล์ข้างนอก

## 7. ข้อมูลผู้ป่วยอยู่ที่ไหน

อยู่ใน `localStorage` ของเบราว์เซอร์บนเครื่องนั้นเครื่องเดียว ภายใต้คีย์ `hsews.v4`

- ไม่มีการส่งออกจากเครื่องไปที่ใดทั้งสิ้น ไม่มีเซิร์ฟเวอร์กลาง ไม่มี analytics
- แต่ละเครื่องเก็บของตัวเอง มองไม่เห็นกัน
- ผู้ป่วยที่ไม่ถูกแตะเกิน 48 ชั่วโมงถูกลบอัตโนมัติ **ตอนเปิดแอป**
  (ไม่ใช่นาฬิกาที่เดินตลอด ถ้าไม่มีใครเปิดแอป ข้อมูลก็ยังอยู่จนกว่าจะเปิดครั้งถัดไป)
- จบเคสแล้วให้กด **จบเคส · ลบรายนี้** ทันที อย่ารอ 48 ชั่วโมง

**ข้อจำกัดที่ต้องรู้** iOS Safari อาจล้างข้อมูลเว็บที่ไม่ได้เข้าเกิน 7 วัน
(ติดตั้งลงหน้าจอโฮมแล้วจะทนกว่า) และล้างข้อมูลเบราว์เซอร์ เปลี่ยนเครื่อง
หรือเปิดโหมดส่วนตัว = ข้อมูลหาย

**ดังนั้นแอปนี้ไม่ใช่เวชระเบียน** คะแนนต้องลงแบบบันทึกกระดาษหรือ HIS เสมอ

## 10. ข้อควรระวังทางคลินิก

คะแนนนี้ยังไม่ผ่านการ validate แบบ prospective
สร้างขึ้นจากหลักการของ Westley croup score, C-CHEWS และ modified PEWS-CHD
จุดตัด 3 / 6 / 10 มาจากการให้เหตุผลเชิงเนื้อหา ยังไม่ได้มาจากข้อมูลผู้ป่วยจริง

ภาพในแท็บแนวทางใช้ดูเร็ว ๆ ข้างเตียง **ขนาดยาและรายละเอียดให้ยึดเอกสารฉบับเต็ม
ของโรงพยาบาลเป็นหลัก** เพราะถ้าแนวทางแก้แล้วลืมอัปเดตแอป ภาพในนี้จะกลายเป็นของเก่า

ระหว่างนี้ให้ใช้เป็นเครื่องช่วยสื่อสารและเฝ้าระวัง
**ไม่ใช่เครื่องมือตัดสินใจแทนการประเมินของแพทย์**
และ "เมื่อไม่แน่ใจ ให้รายงาน" ยังสำคัญกว่าตัวเลขเสมอ
